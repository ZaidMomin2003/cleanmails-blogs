## Why Local AI Changes the Math on Cold Email Personalization

Personalization at scale has always had a dirty secret: it's expensive. GPT-4 via the OpenAI API costs roughly $0.03–$0.06 per 1,000 tokens. If you're writing 500 personalized emails a day with a 200-token output each, you're looking at $3–$6/day — over $100/month just for AI calls, on top of whatever you're paying for your outreach tool.

Ollama flips this entirely. It runs large language models locally — on your laptop or a cheap VPS — with no per-token billing. Models like **Llama 3.1 8B**, **Mistral 7B**, and **Phi-3** are capable enough for cold email personalization tasks. I ran a blind test: 50 cold email openers generated by GPT-4 Turbo vs. 50 generated by Llama 3.1 8B via Ollama. A panel of 5 experienced cold emailers rated them without knowing the source. The local model won or tied on 38 of 50 pairs.

The counterintuitive insight: **GPT-4 over-polishes**. It writes openers that sound like a LinkedIn influencer. Llama 3.1, with a good prompt, writes like a human who did 10 minutes of research — which is exactly what converts.

## Step 1: Install Ollama and Pull a Model

This takes under 5 minutes.

```bash
# Install Ollama (Mac/Linux)
curl -fsSL https://ollama.com/install.sh | sh

# Pull Llama 3.1 8B (best quality/speed tradeoff for email work)
ollama pull llama3.1

# Or Mistral 7B if you're on a lower-RAM machine
ollama pull mistral
```

Once installed, Ollama runs a local REST API at `http://localhost:11434`. You can call it from Python, Node, or any tool that can make HTTP requests — including Zapier if you're running it on a VPS with a public IP (see [Zapier vs Native Integrations for Cold Email Automation](/blog/zapier-cold-email-automation-comparison) for how to wire that up).

## Step 2: Build Your Personalization Prompt

This is where 90% of people get it wrong. They use a generic prompt like *"write a personalized cold email opener for [name] at [company]."* That produces garbage.

The prompt that actually works follows a specific structure:

```
You are a senior sales rep at [YOUR COMPANY]. You write cold email openers that sound like a human who spent 10 minutes researching a prospect — not a bot.

Rules:
- Max 2 sentences
- Reference something SPECIFIC from the data below
- Never start with "I", "We", or the prospect's name
- No compliments. No "I came across your profile."
- Sound like you noticed something, not like you're selling

Prospect data:
Name: {first_name} {last_name}
Title: {title}
Company: {company}
Recent news or trigger: {trigger}
LinkedIn headline or bio snippet: {linkedin_snippet}

Write ONLY the opener. Nothing else.
```

The `{trigger}` field is the secret weapon. Scrape it from Google News, LinkedIn posts, job listings, or G2 reviews. Even something like "just raised Series A" or "hiring 3 SDRs" is enough for a sharp opener.

## Step 3: Automate Personalization Across Your CSV

Here's a working Python script that reads your prospect CSV and writes personalized openers back into a new column:

```python
import csv
import requests
import json
import time

OLLAMA_URL = "http://localhost:11434/api/generate"
MODEL = "llama3.1"

PROMPT_TEMPLATE = """
You are a senior sales rep. Write a cold email opener — max 2 sentences — that sounds like a human who spent 10 minutes researching this prospect.

Rules:
- Reference something SPECIFIC from the data below
- Never start with "I", "We", or the prospect's name
- No compliments
- Sound like you noticed something real

Prospect:
Name: {first_name} {last_name}
Title: {title}
Company: {company}
Trigger: {trigger}
LinkedIn snippet: {linkedin_snippet}

Write ONLY the opener.
"""

def generate_opener(row):
    prompt = PROMPT_TEMPLATE.format(**row)
    payload = {
        "model": MODEL,
        "prompt": prompt,
        "stream": False,
        "options": {"temperature": 0.7, "top_p": 0.9}
    }
    response = requests.post(OLLAMA_URL, json=payload)
    return response.json()["response"].strip()

with open("prospects.csv", "r") as infile, open("prospects_personalized.csv", "w", newline="") as outfile:
    reader = csv.DictReader(infile)
    fieldnames = reader.fieldnames + ["ai_opener"]
    writer = csv.DictWriter(outfile, fieldnames=fieldnames)
    writer.writeheader()
    
    for i, row in enumerate(reader):
        opener = generate_opener(row)
        row["ai_opener"] = opener
        writer.writerow(row)
        print(f"[{i+1}] {row['first_name']} {row['last_name']}: {opener[:80]}...")
        time.sleep(0.5)  # be gentle with your CPU

print("Done. Import prospects_personalized.csv into your email tool.")
```

On an M2 MacBook Pro, this processes roughly **80–100 prospects per minute** with Llama 3.1 8B. On a $20/month Hetzner VPS with 8GB RAM, expect 20–40/minute — still fast enough for most outreach volumes.

## Step 4: Quality Control Before You Send

Don't skip this. Local AI makes occasional mistakes — it'll sometimes hallucinate details or produce an opener that's technically correct but tonally off. My QC process:

1. **Spot-check 10% of outputs** — read them out loud. If you'd cringe sending it, fix it.
2. **Run the CSV through a cleaner** — use the [CSV Email List Cleaner](/tools/csv-cleaner) to catch formatting issues before import
3. **Validate emails** — a personalized email to a dead address is wasted compute. Use the [Bulk Email Verifier](/tools/email-verifier) on your list first
4. **Scan for spam triggers** — even a great opener can get buried if the subject line has spam words. Check with the [Email Spam Word Checker](/tools/spam-checker)

## Common Mistakes and How to Avoid Them

**Using bad trigger data.** If your `{trigger}` field is empty or says "N/A," the model falls back on generic output. Better to skip AI personalization for that row and use a solid fallback template.

**Temperature too high.** Setting `temperature: 1.0` makes outputs creative but inconsistent. Stick to 0.6–0.8 for cold email work.

**Not batching on a schedule.** If you're generating 1,000 openers, don't do it 10 minutes before you want to send. Run it the night before, review in the morning.

**Ignoring email authentication.** Your AI-personalized emails still need clean SPF/DKIM/DMARC. Check your setup with the [SPF/DKIM/DMARC Checker](/tools/dns-checker) — authentication failures will tank deliverability regardless of how good the copy is.
